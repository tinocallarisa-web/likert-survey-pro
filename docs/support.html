Quick start

  1. Drag the survey item into Question — one diverging bar per value.
  2. Drag the scale point into Response (Strongly disagree … Strongly agree).
  3. Drag the count of responses into Value.
  4. Fill in Scale order with a numeric rank, 1 for the leftmost point. This is what fixes the order of the scale.
  5. Set Scale → Negative points to how many points count as negative. On a 5-point agreement scale that is 2, and the third point is treated as the neutral one.
The one thing to get right. Without a defined order, Power BI hands the responses over alphabetically — Agree, Disagree, Neutral, Strongly agree, Strongly disagree. That is not a scale, and a diverging chart built on it means nothing. The visual cannot detect it, so it would draw it wrong without saying so. Use the Scale order well, or sort the response column in the model with Sort by column.

Frequently asked questions

Scale and neutral point

My scale is out of order

Fill in the Scale order well with a numeric rank, or sort the response column in the model. If the well is filled and the order is still wrong, check its aggregation: with one row per respondent, Sum inflates the rank by the number of rows. Set it to Minimum.

What happens to the middle point of the scale?

Scale → Neutral point offers three answers. Split across the centre puts half of it either side, which is the usual convention. Count as positive moves it entirely to the right. Leave out of the bar removes it from the chart and from each question's total, so the remaining percentages are recalculated over the answers that expressed an opinion.

My scale has 4 or 7 points, not 5

Any number of points works. Set Negative points to how many fall on the negative side. With an even number of points there is no middle one, so the neutral setting has nothing to split and can be left as it is.

Reading the chart

What do the two percentages on the right mean? Pro

Top box and bottom box: the share of the most positive answers and of the most negative ones. Top / Bottom box → Box size chooses how many points go into each, so Top-2 on a 5-point scale is Agree plus Strongly agree.

What is the number in the pill? Pro

Top box minus bottom box, on the same idea as a Net Promoter Score. Green at zero or above, red below. Both colours and the text size are configurable.

What is the figure in the circle next to each block?

The block's summary, chosen in Question table → Block score: mean score on the scale, share of positive answers, or NPS. It is weighted by responses, not by questions, so a question answered by 95 people does not count the same as one answered by 250.

Colours

Can I set the colour of each scale point?

The ramp is built from Colors → Negative end, Neutral and Positive end. For full control, the fx button on Scale point drives the colour from a rule.

Can I set the colour of each block? Pro

Yes. Question table shows one colour picker per block, seeded from the report theme, so the colours follow the theme until you override them.

Layout

With many questions the rows are tiny, or I cannot see them all

Layout → Scroll when rows do not fit keeps the rows at a readable height and lets the chart scroll; the legend stays put. Turn it off and the rows shrink so that everything fits at once, which is what you want when the report is exported to PDF or PowerPoint, where only the visible part is captured.

The question text is cut off

The question column sizes itself to the longest question, up to Labels → Question column width. Raise that limit, or reduce the text size.

Ten questions only fill the top half of a tall visual

That was version 1.0. Since 1.1 Layout → Row height is Automatic by default: the rows share the height of the visual, and the bars grow up to 64 px so that two or three questions do not turn into huge blocks. Block bands, question text, labels and the Top/Bottom and NPS columns follow the row. Fixed gives every row the height you type; if they do not all fit, the chart scrolls (with Scroll when rows do not fit on) or a note under the chart says how many questions are not shown.

The visual is small on my page

The layout adapts to three sizes. Below about 400 × 300 px the legend becomes compact (all the swatches, with the two ends named), a narrow block column is dropped while its shading stays, and the Top/Bottom and NPS columns are dropped before the bars shrink. Below about 200 × 140 px only the questions and the bars remain. The diverging bar is always the last thing to go.

Styles and formatting

What does Report theme do, and what do the styles change?

Report theme (free, the default) takes text and block colours from the report theme and keeps the diverging scale red → grey → blue unless you change it. The six collection styles Pro are the same looks as KPI Card, Pareto, Treemap and the rest of TCViz: background, text, axis, gridlines, scale ends, NPS colours, benchmark and block colours. Anything you set by hand in the format pane wins over the style. Without a licence, choosing a style shows it under the watermark while you edit; reading view shows Report theme.

Can I format the chart by clicking on it?

Yes — on-object formatting. With Power BI's on-object interaction turned on, click the bars, the questions, the legend, an axis, the gridlines, a panel title or the background to get its formatting options and shortcuts. In format mode a click selects what to format and never filters the report.

What is the setup guide in the corner?

A three-step guide that shows only while you edit and the visual is at least 420 × 260 px: which fields are in place, buttons to try features on your own data (styles, Top/Bottom box and NPS, benchmark, axis and gridlines, patterns), and a style picker. Close it with ✕ or Finish; turn it back on in Style template → Setup guide. It only changes format settings when you press a button, never the field wells.

Number formats

Values (with Show as percentage off) and tooltips use the format of the measure, including dynamic format strings: when the measure's format changes row by row, each value uses its own.

Small multiples and drilldown

How do small multiples work? Pro

Drag a field to Small multiples. Each value gets its own panel with the same questions in the same order, so a row reads across the grid. Without a licence, while you edit, the first 4 panels show under the watermark and a note says how many there are; in reading view the panels are added together into one chart, which is the correct total.

How do I drill down?

Put a hierarchy, or several fields, in Question — for example Dimension and then Item. Use the drill buttons in the visual header or the context menu. Drilldown is free.

Do bookmarks remember the selection?

Yes: a bookmark that captures a selected segment, question or legend item paints it back when you apply it. Format settings are part of the visual, not of the selection, so a bookmark does not change them.

Licensing

Why do Pro features work without a licence while I am editing?

They render under a Pro preview watermark so you can see what the plan gives before buying, which Microsoft's publishing guidelines allow. In reading view, and wherever Power BI cannot check licences — Publish to Web, embedding, export — the free result is drawn with no watermark. A published report never uses a feature you have not paid for.

I bought Pro and the visual still behaves as free

The licence is read once per session, after the first render. Refresh the report. If it persists, check in the Microsoft 365 admin centre that the licence is assigned to the account opening the report, and write to support@tcviz.com with the tenant name.

Accessibility

The chart is a single Tab stop. Left and right arrows move between segments, up and down move to the same answer in the question above or below, Home and End jump to the ends, Enter or Space selects, Ctrl adds to the selection, Escape clears it and Shift+F10 or the menu key opens the context menu. The focused segment gets a visible outline. Every segment carries a label with its question, scale point and share.

The Accessibility card in the format pane sets:

  • High contrast — Automatic follows the Windows high contrast theme; On forces it. In high contrast the bars are drawn in the system colours with a pattern per scale point, so negative and positive answers stay apart without colour.
  • Focus colour and width of the keyboard outline.
  • Minimum text size for every text the visual writes.
  • Patterns on scale points — hatching whose direction tells the side (negative or positive) and whose density tells the distance from neutral; the neutral point is dotted. The legend uses the same patterns.
