Quick start

  1. Drag the survey item into Question — one diverging bar per value.
  2. Drag the scale point into Response (Strongly disagree … Strongly agree).
  3. Drag the count of responses into Value.
  4. Fill in Scale order with a numeric rank, 1 for the leftmost point. This is what fixes the order of the scale.
  5. Set Scale → Negative points to how many points count as negative. On a 5-point agreement scale that is 2, and the third point is treated as the neutral one.
The one thing to get right. Without a defined order, Power BI hands the responses over alphabetically — Agree, Disagree, Neutral, Strongly agree, Strongly disagree. That is not a scale, and a diverging chart built on it means nothing. The visual cannot detect it, so it would draw it wrong without saying so. Use the Scale order well, or sort the response column in the model with Sort by column.

Frequently asked questions

Scale and neutral point

My scale is out of order

Fill in the Scale order well with a numeric rank, or sort the response column in the model. If the well is filled and the order is still wrong, check its aggregation: with one row per respondent, Sum inflates the rank by the number of rows. Set it to Minimum.

What happens to the middle point of the scale?

Scale → Neutral point offers three answers. Split across the centre puts half of it either side, which is the usual convention. Count as positive moves it entirely to the right. Leave out of the bar removes it from the chart and from each question's total, so the remaining percentages are recalculated over the answers that expressed an opinion.

My scale has 4 or 7 points, not 5

Any number of points works. Set Negative points to how many fall on the negative side. With an even number of points there is no middle one, so the neutral setting has nothing to split and can be left as it is.

Reading the chart

What do the two percentages on the right mean? Pro

Top box and bottom box: the share of the most positive answers and of the most negative ones. Top / Bottom box → Box size chooses how many points go into each, so Top-2 on a 5-point scale is Agree plus Strongly agree.

What is the number in the pill? Pro

Top box minus bottom box, on the same idea as a Net Promoter Score. Green at zero or above, red below. Both colours and the text size are configurable.

What is the figure in the circle next to each block?

The block's summary, chosen in Question table → Block score: mean score on the scale, share of positive answers, or NPS. It is weighted by responses, not by questions, so a question answered by 95 people does not count the same as one answered by 250.

Colours

Can I set the colour of each scale point?

The ramp is built from Colors → Negative end, Neutral and Positive end. For full control, the fx button on Scale point drives the colour from a rule.

Can I set the colour of each block?

Yes. Question table shows one colour picker per block, seeded from the report theme, so the colours follow the theme until you override them.

Layout

With many questions the rows are tiny, or I cannot see them all

Layout → Scroll when rows do not fit keeps the rows at a readable height and lets the chart scroll; the legend stays put. Turn it off and the rows shrink so that everything fits at once, which is what you want when the report is exported to PDF or PowerPoint, where only the visible part is captured.

The question text is cut off

The question column sizes itself to the longest question, up to Labels → Question column width. Raise that limit, or reduce the text size.

Licensing

Why do Pro features work without a licence while I am editing?

They render under a Pro preview watermark so you can see what the plan gives before buying, which Microsoft's publishing guidelines allow. In reading view, and wherever Power BI cannot check licences — Publish to Web, embedding, export — the free result is drawn with no watermark. A published report never uses a feature you have not paid for.

I bought Pro and the visual still behaves as free

The licence is read once per session, after the first render. Refresh the report. If it persists, check in the Microsoft 365 admin centre that the licence is assigned to the account opening the report, and write to support@tcviz.com with the tenant name.

Accessibility

The chart is a single Tab stop. Arrow keys move between segments, Home and End jump to the ends, Enter or Space selects, Ctrl adds to the selection, Escape clears it and Shift+F10 opens the context menu. Every segment carries a label with its question, scale point and share. High contrast mode is honoured through the report theme.
