Getting started

1
Question · Response · Value. One row per question × scale point, with the count in Value.
2
Scale order. The numeric rank of each point, 1 = leftmost.
3
Group [Pro]. Draws the questions as labelled blocks with their mean.
⚠ Scale order is not optional in practice

Without it Power BI hands the responses over alphabetically — Agree, Disagree, Neutral, Strongly agree… — which is not a scale. The visual cannot detect that, so it would draw it wrong without saying so.

Key features

⇄

Centred on the neutral

Disagreement left, agreement right, from one shared axis. Ten questions compare at a glance.

◐

Three neutral modes

Split across the centre, count as positive, or leave out of the bar — percentages recalculate.

↕

Scale order well

Fixes the order of the scale inside the visual. No Sort by column in the model needed.

🎨

Conditional formatting

One fx button governs the whole scale colour — not one per response.

PRO ▣

Top / Bottom box

The share at each end of the scale, beside the bar, at the depth you choose.

PRO ◉

NPS pill

Top minus bottom, drawn as a pill with its own colours and size.

PRO ▤

Question groups

Blocks as labelled sections, each with its mean in a circle, weighted by responses.

PRO ┊

Benchmark line

One line across every question: a target, or the previous wave.

♿

Accessibility

Roving tabindex, arrows, Enter, Escape, Shift+F10. A label per segment for screen readers.

🔒

No network access

privileges is []. No requests, telemetry or storage. No data leaves the report.
