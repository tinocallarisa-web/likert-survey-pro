2. Pro preview

Without a licence, while you are editing a report, Pro features render working under a Pro preview watermark, so you can judge the plan before paying. Microsoft's publishing guidelines allow watermarking paid features. In reading view, and wherever Power BI cannot verify licences — Publish to Web, embedding, export to PDF or PowerPoint — the free result is drawn with no watermark. A published report never uses a Pro feature that has not been paid for.

3. Buying and assigning licences

Pro is bought through Microsoft AppSource under the standard ISV licensing model and assigned per user in the Microsoft 365 admin centre. Every person who views a report using Pro features needs a licence, not only the author. Billing, renewals and refunds are handled by Microsoft, under their terms.

4. Permitted use

The licence allows use of the visual inside Power BI reports, including in commercial work and for clients. It does not allow decompiling the package, redistributing it outside Microsoft AppSource, or reselling it as part of another product.

5. Data and privacy

The visual makes no network requests and stores nothing outside the report. See the privacy policy.
