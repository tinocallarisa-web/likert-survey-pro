The short version: no data leaves your report. The visual makes no network requests, sends no telemetry, sets no cookies and stores nothing outside the report file.

What the visual does with your data

It receives the fields you place in its wells, aggregates them inside the Power BI sandbox and draws the result. The data is held in memory for as long as the visual is on screen and is discarded when it is removed or the report is closed.

What it does not do

  • No network access. The visual declares "privileges": [], which is what allows it to be certified by Microsoft. It contains no fetch, XMLHttpRequest or WebSocket calls, and loads no external fonts, scripts or images.
  • No telemetry or analytics. Nothing is measured, counted or reported.
  • No cookies and no local storage.
  • No external service. There is no companion application and no server to contact. Everything runs in the sandbox Power BI gives the visual.

What is saved in the report

Only your formatting choices — colours, sizes, the settings of each card — which Power BI stores inside the .pbix file like those of any other visual. No survey data and no personal data are written by the visual.

Licensing

Plans are handled entirely by Microsoft AppSource. The visual asks Power BI whether the current user holds a licence, through the Power BI licensing API, and receives yes or no. TCViz does not see your identity, your tenant or your data through that call, and no licence key is stored anywhere.

Support requests

If you write to support@tcviz.com or open a GitHub issue, we keep only what you send us, for as long as it takes to answer. Please do not attach real survey responses: a sample with made-up data is enough to reproduce a problem.
