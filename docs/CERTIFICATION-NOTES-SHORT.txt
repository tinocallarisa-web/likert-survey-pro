PLEASE READ FIRST - PRO PREVIEW
Without a licence, IN EDIT MODE ONLY, Pro options render working under a "Pro preview"
watermark. Intentional, not missing gating. In reading view, before the licence resolves,
and where licences cannot be read (Publish to Web, embed, export) the FREE result is drawn,
no watermark, no notice. The gate is options.viewMode, not Desktop vs Service.

TESTING - FREE (no active plan)
1. Question + Response + Value + Scale order: the diverging scale renders centred.
2. Remove Value: the landing page appears, not an error or blank canvas.
3. In EDIT mode turn on Top/Bottom box, NPS or Benchmark, or drag a field to Group: each
   renders WORKING under the watermark, a banner names it, and after ~10 s the Upgrade
   bar appears.
4. Reading view: free result, no watermark or notice.
5. Click a segment: the report filters; Ctrl+click adds. Tab in, arrows move, Enter
   selects, Escape clears, Shift+F10 the menu.
6. Resize very narrow: the question column is capped, the bars stay visible.
With the "likert-survey-pro-tcviz" plan active they render with no watermark. Its
one-month free trial resolves as Active, same path as a paid licence.

PRIVACY/NETWORK
No network calls, telemetry, cookies or storage; privileges: []; the audit finds no
external requests. No innerHTML/outerHTML: SVG via createElementNS, data via textContent.
ESLint clean, npm audit 0.

LICENSING
IVisualLicenseManager only; no licence key field, no licensing UI of our own. Requested
once after the first render, never blocking it; failure stays Free with no prompts. It
accepts the short plan id or any Service ID ending ".likert-survey-pro-tcviz", state Active
or Warning. isLicenseUnsupportedEnv and isLicenseInfoAvailable honoured; blocked features
use notifyFeatureBlocked + notifyLicenseRequired, cleared by clearLicenseNotification.

KNOWN GAPS (next release)
1. High contrast is partial: the scale takes the theme foreground colours so the
   negative/positive split stays readable; axis and labels keep fixed.
2. No registerOnSelectCallback: a bookmark carrying a selection is not painted back onto
   the segments. Cross-filtering works.
